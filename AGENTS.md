# Commit attribution

- Commits must use only the repository user's configured Git identity for both the author and committer.
- Never add Codex, an AI agent, a bot, or another automated identity to a commit.
- Do not add `Co-authored-by`, `Generated-by`, or similar attribution for an agent to commit messages.
- Do not change `user.name` or `user.email`. Use the Git identity already configured by the user.
